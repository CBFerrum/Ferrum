# W10: qualification

Nothing in this program is qualified. That is what the state says, not modesty: no requirement is `qualified_profile` or
`production_supported`, and the registry refuses to let one be while anything it depends on is blocked, or without an independent
reviewer, of whom there are none (`docs/registry/reviewers.yaml`).

| Check | What it does |
|---|---|
| `python3 scripts/registry.py check` | Evidence cited has to exist, and each state needs what it claims |
| `python3 scripts/test_registry.py` | Takes evidence away and tries false claims, and each has to fail |
| `docs/platform/journeys.yaml` | Every golden journey and how far it got. Only one run whole may say it passes. None has |

See `docs/platform/profiles.md` for where each profile stands, and `stop-ship.md` for the conditions the specification names.
