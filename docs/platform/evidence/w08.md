# W08: messaging and connected operations

Code: this repository's `platform/w08-connections` at `f483109` and `platform/w09-recovery`; CBFerrum/ferrum-app-edge's
`edge/charging` (https://github.com/CBFerrum/ferrum-app-edge/pull/9); CBFerrum/ferrum-app-cloud's `w03-code-builds`.
PostgreSQL 17.9 on macOS arm64, Rust 1.95.0, non-superuser role `ferrum`.

**No charger, meter or gateway hardware was involved in any of this.** `ocpp_it` speaks OCPP over a real WebSocket to a real
journal, and its crash case opens the journal file a second time, which reads what a restart would.

## Found by these tests

- A gateway's transaction numbers came from a counter in memory, so a restart could hand a number a charger still held to
  someone else.
- A charger was told a billing frame had been heard while the frame was only in a queue in memory.
- Nothing distinguished a charger accepting a start from energy flowing.
