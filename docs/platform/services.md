# Who answers for what

Each thing that is offered, who maintains it, how long it is supported, and where a problem goes. Offering something
means someone is on the hook for it, so **until a name goes in a row, that row is not offered**. Names are the company's to
fill in: nothing here has been assigned (`FCP-CLOUD-009`).

| Service | Maintainer | Supported until | Escalation |
|---|---|---|---|
| Ferrum platform | Not assigned | Not set | Not set |
| Cloud: Code | Not assigned | Not set | Not set |
| Cloud: Deploy and `ferrum-serve` | Not assigned | Not set | Not set |
| Cloud: Access | Not assigned | Not set | Not set |
| Cloud: Resources | Not assigned | Not set | Not set |
| Operations and Edge | Not assigned | Not set | Not set |
| ERP and its localizations | Not assigned | Not set | Not set |

A dependency going away is handled by `ferrum task cloud_provider_notice`: see `ferrum-app-cloud/docs/operating-deploy.md`.
