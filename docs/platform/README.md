# The platform program

Ferrum Code, Deploy, Access and Resources, from the handoff of 2 November 2026 (`Ferrum_Claude_Full_Handoff.md`,
digest in [catalog.json](catalog.json)). This is the record of that program as it stands, kept beside the code.
The handoff's ZIP (`requirements.json`, `contracts/`, `examples/`, `validate_handoff.py`) was not supplied, so
its 197 requirements and 197 acceptance cases were taken from the combined document into `catalog.json`.

| Document | What it is |
|---|---|
| [baseline.md](baseline.md), [baseline.json](baseline.json) | What exists: heads, pins, builds and installed versions, as separate facts. Generated by `scripts/baseline.py` |
| [regressions.md](regressions.md) | The earlier findings, re-run against the assembled release |
| [decisions.md](decisions.md) | Consequential decisions, with what was rejected and why |
| [contract-map.md](contract-map.md) | The handoff's proposed names, against what exists |
| [plan.md](plan.md) | The order of work, and what waits on someone else |
| [traceability.md](traceability.md) | Every requirement's state. Generated from [docs/registry/fcp.yaml](../registry/fcp.yaml) |

## States

A state says what the evidence supports. `scripts/registry.py` refuses a state its evidence does not reach.

| State | What it takes |
|---|---|
| `not_started` | Nothing exists |
| `partial` | Something exists, and the entry says what is missing |
| `implemented_unverified` | Code exists; its acceptance case has not been run as written |
| `verified_software` | The acceptance case ran, in software, with the tests named. Says nothing about a real provider or equipment |
| `qualified_profile` | Verified for a named profile, against a released digest, reviewed by a person |
| `production_supported` | That, and someone has taken on supporting it |
| `verification_failed` | It was run and it failed |
| `blocked_external` | Waits on something named in [blockers.yaml](../registry/blockers.yaml) |

A simulator proves a software scenario, not equipment. A provider mock proves Ferrum's side of a contract, not
the provider. A green build proves it compiles.
